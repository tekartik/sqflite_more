# exp1_sqflite_ffi

Exp1 todo lists app, variant `sqflite_ffi`: sqflite_ffi (SQLite bundled by package:sqlite3, databases in the application support directory).

Platforms: Android, iOS, macOS, Linux, Windows. The UI and the database code are in
[exp1_common](../exp1_common), see the [exp1 README](../README.md) to run it
and its scenarios.
